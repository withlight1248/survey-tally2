## 10×10 오목

한 화면에서 두 사람이 번갈아 둔다.

- 흑이 먼저 두고 흑·백이 번갈아 둔다.
- 칸을 누르면 그 자리에 돌이 놓인다. 키보드로는 방향키로 칸을 옮기고 Enter 또는 Space로 둔다.
- 가로·세로·대각선으로 같은 색 돌이 다섯 개 이상 이어지면 이긴다(6목 이상도 승리, 금수 없음). 이긴 줄은 빨간 테두리로 보인다.
- 100칸이 가득 차도 승자가 없으면 무승부.
- 「한 수 무르기」는 마지막 수를 되돌린다. 「새 게임」은 확인 없이 바로 새로 시작한다.

## 옷입히기

여자 캐릭터 한 명에게 옷을 입힌다. 오른쪽 진열대에 드레스 4벌, 상의 4벌, 하의 4벌이 있다(좁은 화면에서는 캐릭터 아래).

- 진열대의 옷을 누르면 입고, 입은 옷을 다시 누르면 벗는다.
- 상의와 하의는 함께 입을 수 있다. 드레스를 입으면 상의·하의가 벗겨지고, 상의나 하의를 입으면 드레스가 벗겨진다.
- 「기본 차림으로」는 모두 벗고 처음 상태로 돌린다.
- 캐릭터와 옷은 전부 직접 그린 도형(SVG)이다.

## 식단 볼

점심·간식·저녁 나무볼 3개에 음식을 담고, 볼을 완성하면 칼로리와 탄수화물·단백질·지방을 계산한다. 음식은 오른쪽 선반에 있다(좁은 화면에서는 볼 아래).

- 선반의 음식을 누르면 선택된 볼에 1회 제공량씩 담긴다. 같은 음식을 여러 번 담을 수 있고, 볼 안의 이름표를 누르면 1개씩 뺀다.
- 「완성!」을 누르면 그 볼의 칼로리·탄단지가 나오고 볼이 잠긴다(다음 빈 볼이 자동 선택). 「다시 담기」로 다시 열 수 있다.
- 하루 목표는 160cm·22세 여성(근육 늘리고 지방 줄이기), 체중 60kg 기준으로 시작한다. 체중은 바꿀 수 있고 목표도 따라 바뀐다. 계산 근거는 [diet-bowl/PLAN.md](diet-bowl/PLAN.md).
- 하루 합계는 완성한 볼만 더한다. 영양값은 참고용 추정치다.

## 시험

Node.js 20 이상이면 된다(22에서 확인). 설치할 것은 없다.

```
npm test
```

게임마다 규칙(순수 함수)을 화면과 떼어 `index.html` 안의 별도 `<script>` 블록에 두었고, 시험이 그 블록만 꺼내 실행한다. `tests/constraints.test.js`는 세 페이지 모두 외부 주소·글꼴·분석 코드·저장·전송 API가 없는지, 외부 연결을 막는 CSP가 있는지 확인한다.
