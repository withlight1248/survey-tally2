# survey-tally2

엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표를 보여 주는 설문 집계기. `index.html` 한 장이고, 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않는다. 붙여넣은 데이터는 브라우저 밖으로 보내지 않고 저장하지도 않는다.

## 쓰는 법

`index.html`을 브라우저로 열고(GitHub Pages로 올려도 된다), 엑셀에서 응답번호 열과 머리글 줄까지 포함해 복사한 뒤 입력칸에 붙여넣는다.

| 응답번호 | 만족도 | 추천 |
| --- | --- | --- |
| 1 | 5 | 4 |
| 2 | 4 | |
| 3 | 3 | 5 |

결과 표는 문항 / 유효 응답 / 평균 / 빈 응답 / 제외 순서로 나온다.

## 집계 규칙

- 첫 열(응답번호)은 집계하지 않는다.
- 칸은 앞뒤 공백을 지운 값으로 판정한다.
  - `1`·`2`·`3`·`4`·`5` 중 하나: 유효 응답
  - 비었거나 공백만 있음: 빈 응답
  - 그 밖의 값: 제외
- 평균 = 유효 응답의 합 ÷ 유효 응답 수, 소수 셋째 자리에서 반올림해 둘째 자리까지. 유효 응답이 0이면 `-`.
- 칸 수가 머리글보다 모자란 줄은 모자란 칸을 빈 응답으로 센다. 넘치는 칸은 무시한다.
- 모든 칸이 빈 줄은 건너뛴다.

## 시험

Node.js 20 이상이면 된다(22에서 확인). 설치할 것은 없다.

```
npm test
```

계산 로직은 `index.html`의 `<script id="tally-logic">` 블록에 화면과 떼어 두었고, 시험이 그 블록만 꺼내 실행한다. `tests/constraints.test.js`는 외부 주소·글꼴·분석 코드·저장·전송 API가 없는지, 외부 연결을 막는 CSP가 있는지 확인한다.

자세한 설계는 [PLAN.md](PLAN.md)를 본다.
