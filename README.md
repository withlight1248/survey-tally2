# 10×10 오목

브라우저에서 두 사람이 한 화면을 번갈아 눌러 두는 10×10 오목. `index.html` 한 장이고, 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않는다. 외부로 연결하거나 저장하지 않는다.

## 하는 법

`index.html`을 브라우저로 열면 바로 시작한다(GitHub Pages로 올려도 된다).

- 흑이 먼저 두고 흑·백이 번갈아 둔다.
- 칸을 누르면 그 자리에 돌이 놓인다. 키보드로는 방향키로 칸을 옮기고 Enter 또는 Space로 둔다.
- 가로·세로·대각선으로 같은 색 돌이 다섯 개 이상 이어지면 이긴다(6목 이상도 승리, 금수 없음). 이긴 줄은 빨간 테두리로 보인다.
- 100칸이 가득 차도 승자가 없으면 무승부.
- 「한 수 무르기」는 마지막 수를 되돌린다. 승부가 난 뒤에도 쓸 수 있다.
- 「새 게임」은 확인 없이 바로 새로 시작한다.

컴퓨터 상대는 없고, 한 화면에서 둘이 번갈아 두는 방식이다.

## 시험

Node.js 20 이상이면 된다(22에서 확인). 설치할 것은 없다.

```
npm test
```

규칙은 `index.html`의 `<script id="omok-logic">` 블록에 화면과 떼어 두었고, 시험이 그 블록만 꺼내 실행한다. `tests/constraints.test.js`는 외부 주소·글꼴·분석 코드·저장·전송 API가 없는지, 외부 연결을 막는 CSP가 있는지 확인한다.

설계와 정한 점은 [PLAN.md](PLAN.md)를 본다.
