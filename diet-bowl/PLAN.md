# 식단 볼 게임 계획서

점심·간식·저녁 세 개의 나무볼에 음식을 담고, 볼을 완성하면 그 볼의 칼로리와 탄수화물·단백질·지방을 계산해 주는 식단 관리 게임. `diet-bowl/index.html` 한 장으로 만든다.

## 1. 요구사항

1. 화면 왼쪽에 **점심 / 간식 / 저녁** 나무볼 세 개를 **세로**로 배치하고, 오른쪽 **선반**에 음식을 진열한다.
2. 음식: 구운란, 구운란 흰자, 요거트 80g, 하루견과 1봉, 단백질음료(단백질 20g 기준), 연어초밥 1피스, 불닭볶음면 소컵, 진라면 소컵, 후레쉬베리, 초콜릿 1조각 + 기본적인 식재료(닭가슴살, 두부, 현미밥, 고구마 등).
   - 추가 요청(2차): 후레쉬베리는 한국 과자, 현미밥 130g, 삼겹살 100g, 안심돈가스, 쌀국수 1그릇, 미니단호박 1/4, 김치, 초코 휘낭시에.
3. 모든 음식은 **중복으로 담을 수 있다**. 서브웨이처럼 다 담고 볼을 **완성**하면 그 볼의 칼로리와 탄수화물·단백질·지방을 계산한다.
4. 섭취 목표는 **160cm, 22세 여성, 근육 증가 + 지방 감소**. **체중 60kg 기준**으로 시작한다.
5. 파일은 `index.html` 하나. 외부 라이브러리·외부 이미지·외부 글꼴·분석 도구를 쓰지 않고, 외부로 연결하거나 저장하지 않는다.

## 2. 섭취 목표 계산 (60kg 기준)

체중은 화면에서 바꿀 수 있고(40~120kg), 시작값은 60kg이다. 키 160cm·나이 22세·여성은 고정이다.

| 단계 | 식 | 60kg일 때 |
| --- | --- | --- |
| 기초대사량 (Mifflin-St Jeor, 여성) | 10×체중 + 6.25×키 − 5×나이 − 161 | 1,329 kcal |
| 하루 소비량 | 기초대사량 × 1.55 (주 3~4회 근력운동 가정) | 2,060 kcal |
| 목표 열량 | 소비량 × 0.85 (15% 감량), 10 단위 반올림 | **1,750 kcal** |
| 단백질 | 체중 1kg당 2.0g | **120 g** |
| 지방 | 체중 1kg당 0.8g | **48 g** |
| 탄수화물 | 남는 열량 ÷ 4 | **210 g** |

근거: 근육을 늘리면서 지방을 줄이는 목적(체성분 재구성)에서는 "완만한 열량 감량 + 높은 단백질 + 근력운동"이 일반적인 권장 방향이다. 단백질은 체중 1kg당 1.6g 이상에서 근육 증가가 보고되어 있고 연구에서는 그 이상(2.0~2.4g)도 쓰인다. 열량 감량은 하루 250~500kcal 정도의 완만한 수준을 권한다. 위 계산은 이 방향을 따른 **참고용 추정**이며 의학적 조언이 아니다.

## 3. 명세에 없어서 정한 점

| 항목 | 정한 것 | 이유 |
| --- | --- | --- |
| 활동량 | 주 3~4회 근력운동 (× 1.55) | 근육 증가가 목적이라 운동을 한다고 가정. 코드 상수라 바꾸기 쉽다. |
| 감량폭 | 하루 소비량의 15% (60kg 기준 약 310kcal) | 근육을 지키며 지방을 줄이는 완만한 폭. |
| 세 볼의 의미 | 점심·간식·저녁 세 볼이 **그날 먹는 전부**다(아침은 없음). 하루 목표는 완성한 볼들의 합과 비교한다. | 요청이 세 칸으로 정해져 있어서. |
| 열량 공개 시점 | 볼을 완성하기 전에는 담은 음식만 보이고, 칼로리·탄단지는 **완성한 뒤에** 계산해 보여 준다. | "다 담고 완성하면 계산"이라는 요청대로. |
| 완성 후 | 「다시 담기」로 볼을 다시 열어 고칠 수 있다. 완성하려면 음식이 한 가지 이상 있어야 한다. | 실수 되돌리기. |
| 담는 볼 | 한 번에 한 볼에 담는다(선택된 볼). 볼을 완성하면 다음 빈 볼로 넘어간다. | 선반 하나로 세 볼에 담기 위해. |
| 음식 양 | 음식마다 1회 제공량을 정해 두고 누를 때마다 1회 제공량씩 담는다. | 중복 담기 = 개수 늘리기. |
| 초콜릿 | 다크 초콜릿(카카오 70% 안팎) 10g을 1조각으로 본다. | 요청에 종류가 없어서. 밀크 초콜릿이면 열량이 비슷하고 당이 더 많다. |
| 요거트 | 플레인(무가당) 80g | 요청에 종류가 없어서. |
| 후레쉬베리 | 오리온 과자 후레쉬베리 1봉지(28g). 처음에 생과일 베리로 잘못 알았다가 사용자 지적으로 바로잡음. | 한국 과자라서 '견과·간식'에 둔다. |
| 현미밥 | 이전의 '밥 1공기 210g'을 '현미밥 130g'으로 바꿈. | 사용자 요청(130g). 시판 현미밥 130g 제품 값 사용. |
| 삼겹살·돈가스·쌀국수 | 삼겹살은 구운 것 100g, 안심돈가스·쌀국수는 시판·식당 1인분 평균 | 제품·가게마다 차이가 커서 대표값을 고름. |
| 미니단호박 | 1/4개를 70g(찐 것)으로 본다. | 미니단호박 한 개가 약 250~300g이라는 추정. 영양은 일반 단호박 값에서 계산한 추정. |
| 그림 | 음식은 기기 기본 이모지(글자)로 표시하고, 볼은 CSS로 그린 나무볼이다. | 외부 이미지·글꼴 없이 한 장으로 만들기 위해. 이모지 모양은 기기마다 조금 다르다. |

## 5. 구성

```
diet-bowl/index.html   화면 + 규칙 + 음식 데이터 (한 파일)
diet-bowl/PLAN.md      이 문서
tests/                 자동 시험 (다른 게임과 같은 폴더)
```

`diet-bowl/index.html` 안은 두 블록으로 나눈다.

1. `<script id="diet-logic">`: 규칙과 데이터. 화면 요소를 쓰지 않는 순수 함수. 음식 목록(`FOODS`), 목표 계산(`targets`), 담기·빼기·비우기·완성·다시 담기, 볼 합계(`mealTotals`), 하루 합계(`dayTotals`), 목표 비교(`compare`). 상태는 바꾸지 않고 새 상태를 돌려준다.
2. `<script id="diet-ui">`: 볼과 선반을 그리고 클릭을 규칙에 넘긴다. 계산하지 않는다.

## 6. 화면

- 위: 프로필 한 줄(160cm · 22세 · 여성 · 체중 입력칸)과 하루 목표(열량·탄수·단백질·지방).
- 왼쪽: 점심 → 간식 → 저녁 나무볼이 세로로. 선택된 볼은 테두리로 표시, 볼을 누르면 그 볼이 선택된다. 볼 안에는 담은 음식이 쌓이고, 아래에 "구운란 ×2" 같은 칩이 있어 누르면 하나씩 뺀다. 「완성!」 / 「비우기」 버튼.
- 완성한 볼은 칼로리와 탄수·단백질·지방, 하루 목표 대비 %를 보여 주고 「다시 담기」로 연다.
- 오른쪽: 음식 선반(단백질 / 탄수화물 / 채소·과일 / 견과·간식). 음식을 누르면 선택된 볼에 담긴다.
- 아래: 하루 합계(완성한 볼만)와 목표까지 남은 양·초과량.
- 좁은 화면에서는 선반이 볼 아래로 내려온다. 키보드로도 조작할 수 있다.

## 7. 시험 계획

- 목표 계산: 60kg에서 1,750kcal / 탄수 210g / 단백질 120g / 지방 48g, 체중이 늘면 단조 증가, 범위 밖 체중은 거부, 탄수 계산이 열량과 맞음.
- 음식 데이터: 아이디·이름 중복 없음, 요청한 음식이 모두 있음, 값이 숫자이고 음수가 아님, 열량과 탄단지의 정합성.
- 담기: 중복 담기, 빼기, 비우기, 완성한 볼에는 담을 수 없음, 빈 볼은 완성할 수 없음, 다시 담기, 모르는 음식·볼 무시, 이전 상태를 바꾸지 않음.
- 계산: 볼 합계(열량·탄수·단백질·지방)가 음식 값의 합과 같고 소수 첫째 자리까지 반올림, 하루 합계는 완성한 볼만 더함, 목표 비교(남음/초과/퍼센트).
- 제약 점검: 외부 주소·글꼴·분석 코드·저장·전송 API가 없고 외부 연결을 막는 CSP가 있음.
- 화면은 헤드리스 Chrome으로 실제로 눌러 보고 스크린샷으로 확인한다.
